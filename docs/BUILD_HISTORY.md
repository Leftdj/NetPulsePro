## 版本发布配套产物

每次正式发布需同步以下位置的版本号（参见 [RELEASE_TEMPLATE.md](RELEASE_TEMPLATE.md)）：

1. `app/build.gradle.kts` —— `versionCode` 与 `versionName`
2. `app/src/main/java/com/flowstats/app/data/AppUpdate.kt` —— `history` 列表新增对应条目
3. `download-site/version.json` —— 下载站版本清单（App 内「检测更新」读取此文件）
4. `CHANGELOG.md` —— 正式变更日志
5. GitHub Release —— 仓库「发行版」入口，附带 APK 资产
